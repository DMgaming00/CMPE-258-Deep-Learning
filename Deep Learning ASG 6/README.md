# 📘 Deep Learning Design Space Exploration using Google Colabs

## 📌 Overview

This repository presents a comprehensive exploration of core deep learning concepts through hands-on Google Colab notebooks. Each notebook is executed, analyzed, and explained in depth through accompanying video walkthroughs.

The goal of this project is to bridge theoretical understanding and practical implementation of deep learning systems.

## 📚 Topics Covered

### Activation Functions
- Sigmoid, Tanh, ReLU, GELU
- Vanishing gradient problem
- Importance of non-linearity

### CNN Fundamentals
- Convolution operation
- Feature maps and kernels
- Pooling and architecture basics

### Modern CNN Architectures
- ResNet, DenseNet, EfficientNet
- Skip connections and deep training

### Optimizers
- Gradient Descent, SGD, Adam
- Learning rate strategies

### Classification Metrics
- Confusion Matrix
- Precision, Recall, F1 Score
- ROC-AUC

### Hyperparameter Tuning
- Grid Search, Random Search
- Learning rate importance
- Optimization strategies
